## 2. 세부 작업 계획

### Step 1. `app.py` 및 `main.py` 수정
1. **`DEFAULT_PREFIX` 환경변수 처리 (`app.py`)**:
   - `RAW_PREFIX = os.getenv("DEFAULT_PREFIX", "/templates").strip()`
   - 빈 문자열(`""`) 또는 `"/"`인 경우 `PREFIX = ""`, 그 외에는 선행 슬래시 보장 및 후행 슬래시 제거(`"/" + RAW_PREFIX.strip("/")`).
2. **Database 영속 볼륨 `DATABASE_PATH` / `DATA_DIR` 환경변수 연동 및 자동 시딩 (`app.py`)**:
   - `SEED_DATA_DIR = BASE_DIR / "data"` (이미지 빌드 시 포함되는 원본 데이터 경로 또는 `/app/seed_data` 백업 경로).
   - `DATA_DIR = Path(os.getenv("DATABASE_PATH", os.getenv("DATA_DIR", str(SEED_DATA_DIR)))).resolve()`
   - `ensure_persistent_data_seeded()` 함수를 통해 컨테이너 기동 시 `DATA_DIR` 디렉토리를 생성하고, `styles_metadata.json`, `layouts_metadata.json`, `twayworks_profile.json` 파일이 없으면 시드 데이터에서 자동 복사.
3. **헬스체크 엔드포인트 `GET /api/status` 추가 (`app.py`)**:
   - `@api_router.get("/status")` 및 `@api_router.get("/health")` 모두 동일한 상태 응답(`status: "ok"`, `prefix`, `database_path`, `total_representative_styles`, `total_representative_layouts` 등)을 반환하도록 구성.
4. **동적 HTML 주입 (`serve_sample_homepage`)**:
   - `static/index.html` 서빙 시 `<head>`에 `<script>window.__DEFAULT_PREFIX__ = "...";</script>`를 주입하고, 하드코딩된 `/templates/docs` 링크를 `{PREFIX}/docs`로 동적 치환하여 어떤 `DEFAULT_PREFIX`에서도 100% 작동하도록 처리.
5. **`main.py` 생성**:
   - `from app import app`을 노출하여 `uvicorn main:app --host 0.0.0.0 --port 5000` 및 `gunicorn ... main:app`이 그대로 동작하도록 구성.

### Step 2. 프론트엔드 `static/js/design-helper.js` 수정
- 상단 `API_PREFIX` 계산 로직을 개선하여:

  2. 없을 경우 현재 `window.location.pathname`에서 첫 세그먼트 또는 `/templates` 여부를 감지하여 동적 결정.
