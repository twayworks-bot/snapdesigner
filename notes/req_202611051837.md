2. **Design Templates Helper 시스템 구축 핵심 요구사항 정의**:
   - **[요구사항 1] 정체성 기반 디자인 템플릿 선택 및 CI/샘플 홈페이지 실시간 변환**:
     - 사용자가 기업의 정체성 키워드(형용사, 동사, 타깃 업종)를 선택하거나 10대 대표 디자인 템플릿을 선택하면, **TheWayWorks 샘플 홈페이지 전체(색상 토큰, 폰트 패밀리/웨이트, 보더/곡률/그림자, 히어로 영역 분위기, CI 로고 마크 및 톤앤매너 슬로건 배너)**가 선택된 디자인 스타일로 실시간 변경(Live Theme & Layout Switching)되는 인터랙티브 환경 구축.
   - **[요구사항 2] 디자인 패키지 참조 REST API 엔드포인트 제공**:
     - 외부 웹앱이나 AI 코딩 에이전트(VAIYER 등)가 디자인 스타일 및 템플릿 패키지를 즉시 참조할 수 있는 표준 API 제공:
       - `GET /api/styles`: 전체 스타일 목록 및 필터링(형용사/동사/업종 검색)
       - `GET /api/styles/{style_id}`: 특정 스타일 상세 메타데이터 및 CI 가이드 조회
       - `POST /api/styles/recommend`: 정체성(형용사/동사) 기반 최적 디자인 템플릿 매칭 추천
       - `GET /api/styles/{style_id}/tokens.css`: 선택 스타일의 CSS Custom Properties(`:root` 디자인 토큰) 즉시 참조용 엔드포인트
       - `GET /api/styles/{style_id}/package`: 선택 스타일의 통합 디자인 패키지(메타데이터 + CSS 토큰 + AI 프롬프트 가이드 + 샘플 템플릿 구조) JSON 참조 엔드포인트
   - **[요구사항 3] 디자인 템플릿 패키지(`.zip`) 다운로드 기능 제공**:
     - 선택된 디자인 스타일과 커스텀 CI 정보가 반영된 독립 실행형 템플릿 패키지를 ZIP 파일로 즉시 생성·다운로드(`GET /api/styles/{style_id}/download`)하는 기능:
       - 포함 파일: `design-tokens.css`, `style-metadata.json`, `CI_AND_STYLE_GUIDE.md` (AI 코딩 프롬프트 포함), 그리고 선택 스타일이 적용된 TheWayWorks 샘플 홈페이지 보일러플레이트(`index.html`, `styles.css`, `app.js`, `img/`).
