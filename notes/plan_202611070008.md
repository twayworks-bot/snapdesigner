# Gemini LLM 기반 [디자인 스타일 & 레이아웃 스타일] 생성·등록·관리 스튜디오 구축 계획서 (2026-11-07 00:08)

## 1. 시스템 아키텍처 확장 설계

### 1.1. 환경변수(`.env`) 및 Gemini AI 연동 모듈 (`app.py`)
- `.env` 로더: `python-dotenv` 및 자체 파서를 통해 현재 디렉토리(`C:\Dev\python\snapcompany\templates\.env`) 및 상위 디렉토리(`C:\Dev\python\snapcompany\.env`, `C:\Dev\python\.env`)에서 `GEMINI_API_KEY`를 탐색·로드.
- Gemini API 호출 (`gemini-2.5-flash` / `gemini-2.0-flash` REST/SDK 연동):
  - **1) 디자인 스타일 AI 생성기 (`generate_style_with_gemini`)**:
    - 입력: 사용자 자연어 프롬프트(스타일 컨셉, 타깃 업종, 분위기, 선호 컬러 등) + 선택적 기본값
    - 출력: `styles_metadata.json` 규격과 100% 호환되는 JSON 객체 (`id`, `order`, `name_ko`, `name_en`, `tagline`, `target_businesses`, `template_definition`, `identity`, `colors`, `typography`, `is_custom: true`, `created_by: "gemini-ai"`).
  - **2) 웹사이트 레이아웃 AI 생성기 (`generate_layout_with_gemini`)**:
    - 입력: 사용자 자연어 프롬프트(사업 도메인, 참조 사이트/서비스, 원하는 Head 구성, 원하는 Body 그리드/위젯 구성 등)
    - 출력: `layouts_metadata.json` 규격과 100% 호환되는 JSON 객체 (`id`, `order`, `domain_ko`, `domain_en`, `name_ko`, `name_en`, `representative_companies`, `layout_structure`, `tagline`, `head_spec`, `body_spec`, `domain_keywords`, `recommended_styles`, `sample_application_note`, 그리고 기존 샘플 웹에 즉시 렌더링하기 위한 **`live_template_config`** — `archetype`, `head_nav_items`, `head_Search_placeholder`, `head_cta_label`, `hero_banner_title`, `hero_banner_subtitle`, `body_grid_type`, `sidebar_position`, `sidebar_widgets`, `card_display_style`, `custom_css` 포함).

### 1.2. 백엔드 REST API 확장 (`/templates/api/...`)
1. **AI 상태 확인 API**:
   - `GET /templates/api/ai/status`: `.env`의 `GEMINI_API_KEY` 로드 여부 및 사용 모델 상태 반환.
2. **디자인 스타일(Design Styles) 생성·등록·수정·삭제 API**:
   - `POST /templates/api/styles/ai-generate`: 자연어 프롬프트로 Gemini AI가 신규 디자인 스타일 JSON 초안을 생성(미리보기 또는 즉시 등록 선택 가능).
   - `POST /templates/api/styles`: 신규 디자인 스타일을 `data/styles_metadata.json`에 등록 및 저장.
   - `PUT /templates/api/styles/{style_id}`: 기존 또는 신규 디자인 스타일 메타데이터(컬러, 폰트, 슬로건, 정체성 등) 수정 및 저장.
   - `DELETE /templates/api/styles/{style_id}`: 선택한 디자인 스타일 삭제 (`style-00` 기본 오리지널은 보호).
3. **웹사이트 레이아웃 스타일(Layout Styles) 생성·등록·수정·삭제 API**:
   - `POST /templates/api/layouts/ai-generate`: 자연어 프롬프트로 Gemini AI가 신규 웹사이트 레이아웃(Head & Body 명세 + 라이브 렌더링 설정) JSON 초안을 생성.
   - `POST /templates/api/layouts`: 신규 웹사이트 레이아웃을 `data/layouts_metadata.json`에 등록 및 저장.
   - `PUT /templates/api/layouts/{layout_id}`: 기존 또는 신규 웹사이트 레이아웃(Head/Body 설명, 구성요소, 그리드 규격, 라이브 설정 등) 수정 및 저장.
   - `DELETE /templates/api/layouts/{layout_id}`: 선택한 웹사이트 레이아웃 삭제 (`layout-00` 기본 기업형은 보호).

### 1.3. 프론트엔드 디자인 스튜디오 매니저 UI (`static/index.html`, `static/js/design-helper.js`, `static/css/design-helper-ui.css`)
- 상단 컨트롤 바에 **`✨ AI 스타일·레이아웃 생성 & 통합 관리 스튜디오`** 메인 버튼 추가.
- 클릭 시 열리는 **Design Studio Manager 모달**을 2대 분류 탭으로 구성:
  - **탭 1: `🎨 디자인 스타일 (Tone & Manner) 관리 및 AI 생성`**
    - 좌측: **현재 등록된 디자인 스타일 목록** (기본 11종 + 신규 커스텀 스타일 카운트, 검색, `[즉시 적용]`, `[수정]`, `[삭제]`)
    - 우측 상단: **🤖 Gemini AI로 신규 디자인 스타일 자동 생성기** (예: *"사이버펑크 네온 게이밍 기어 브랜드 스타일 만들어줘"*, *"프랑스 파리 감성의 빈티지 플라워 부티크 스타일"* 등 한 줄 입력 시 AI가 컬러 8종·폰트·형용사·동사·슬로건을 자동 설계하여 폼에 채워줌)
    - 우측 하단: **상세 편집 & 신규 등록 폼** (스타일명, 태그라인, 형용사/동사, 8종 컬러 피커 + HEX 입력, 폰트 패밀리, 보더/그림자 규칙 → `[💾 저장 및 샘플 웹에 즉시 적용]`)
  - **탭 2: `📐 웹사이트 레이아웃 스타일 (Head & Body) 관리 및 AI 생성`**
    - 좌측: **현재 등록된 웹사이트 레이아웃 목록** (기본 11종 + 신규 커스텀 레이아웃 카운트, 검색, `[즉시 적용]`, `[수정]`, `[삭제]`)
    - 우측 상단: **🤖 Gemini AI로 신규 웹사이트 레이아웃 자동 생성기** (예: *"당근마켓/번개장터 같은 로컬 중고거래 & 동네 커뮤니티 하이브리드 레이아웃 만들어줘"*, *"핀터레스트(Pinterest) 스타일의 무한 메이슨리 핀보드 레이아웃"*, *"스포티파이/멜론 같은 하단 고정 플레이어 + 플레이리스트 그리드 레이아웃"* 등 입력 시 AI가 Head/Body 구조와 라이브 레이아웃 아키타입 설정을 자동 생성)
    - 우측 하단: **레이아웃 상세 편집 & 신규 등록 폼** (도메인명, 레이아웃명, 대표 업체, 레이아웃 구조, Head 구조명/설명/요소, Body 구조명/그리드 템플릿/설명/요소, 라이브 렌더링 아키타입 선택 및 커스텀 CSS → `[💾 저장 및 샘플 웹에 즉시 적용]`)
- **동적 레이아웃 렌더러(`buildDynamicCustomLayout`) 구현**:
  - 신규 등록된 커스텀 레이아웃(`layout-11-...` 등)을 선택하면, 해당 레이아웃의 `head_spec`, `body_spec`, `live_template_config`를 해석하여 기존 샘플 웹(TheWayWorks 12종 스낵 앱, 카툰, 코어 엔진)을 해당 신규 Head + Body 구조(메이슨리 핀보드, 좌/우 사이드바 + 피드, 상단 위젯바 + 멀티 그리드, 하단 독 바, 스플릿 뷰 등)로 즉시 렌더링!
