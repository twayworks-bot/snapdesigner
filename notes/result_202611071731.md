1. **Docker 컨테이너 빌드 및 배포 구성 (`Dockerfile`, `.dockerignore`, `requirements.txt`, `gunicorn.conf.py`)**:
   - **Database 영속 볼륨(Persistent Volume) PATH 환경변수 설정**:
     - `ENV DATABASE_PATH=/app/data` 및 `ENV DATA_DIR=/app/data`, `VOLUME ["/app/data"]` 설정.
     - 이미지 빌드 시 초기 JSON 데이터베이스(`styles_metadata.json`, `layouts_metadata.json`, `twayworks_profile.json`)를 `/app/seed_data`에 백업하고, 컨테이너 시작 시 마운트된 볼륨이 비어 있으면 자동 시딩(`ensure_persistent_data_seeded()`)되도록 구현.

   - **기본 Base URL Prefix 설정**: `ENV DEFAULT_PREFIX=/templates`
   - **컨테이너 헬스체크(`HEALTHCHECK`) 정의**:
     ```dockerfile
     HEALTHCHECK --interval=30s --timeout=10s --retries=3 --start-period=5s \
         CMD python -c "import os, requests; prefix = os.getenv('DEFAULT_PREFIX', ''); requests.get(f'http://localhost:5000{prefix}/api/status')"
     ```
   - **시작 `CMD` 설정 (`main:app`)**:
     - `CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "5000"]`를 기본 활성으로 설정하고, 요청된 Gunicorn 운영서버 기동 `CMD`를 함께 기록 및 `gunicorn.conf.py`(`worker_class = "uvicorn.workers.UvicornWorker"`)를 통해 두 명령어 모두 즉시 작동하도록 구성.
