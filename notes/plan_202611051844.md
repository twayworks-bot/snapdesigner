# Design Templates Helper 시스템 FastAPI (`/templates`, Port 5000) 세부 구현 계획서 (2026-11-05 18:44)

---

## 1. 서버 및 라우팅 아키텍처 명세

- **프레임워크**: Python `FastAPI` + `Uvicorn`
- **기본 실행 포트**: `5000` (`python app.py` 실행 시 `0.0.0.0:5000` 바인딩)
- **시작 SUBPATH PREFIX**: `/templates`

### 1.1 엔드포인트 라우팅 테이블

| 구분 | URL 경로 (`PREFIX = /templates`) | 역할 및 설명 |
|:---:|:---|:---|
| **메인 UI** | `GET /templates/` (및 `/templates`, `/`) | TheWayWorks 샘플 홈페이지 + 상단 Design Helper Studio 통합 웹앱 |
| **API 문서** | `GET /templates/docs` | FastAPI Swagger UI 대화형 API 문서 |
| **상태 확인** | `GET /templates/api/health` | 서버 상태, 포트(`5000`), Prefix(`/templates`), 스타일 수 확인 |
| **기업 프로필** | `GET /templates/api/company/twayworks` | TheWayWorks 4대 핵심 축, 4대 코어 부품, 12종 스낵 앱 메타데이터 조회 |
| **스타일 목록** | `GET /templates/api/styles` | 10대 디자인 템플릿 목록 조회 및 형용사/동사/업종/스킴 필터링 |
| **스타일 추천** | `POST /templates/api/styles/recommend` | 정체성 키워드(`adjectives`, `verbs`, `target_business`) 매칭 점수 계산 및 추천 |
| **스타일 상세** | `GET /templates/api/styles/{style_id}` | 특정 디자인 스타일의 상세 메타데이터 및 하위 엔드포인트 링크 조회 |
| **CSS 토큰 참조** | `GET /templates/api/styles/{style_id}/tokens.css` | 외부 웹앱 `<link rel="stylesheet">`로 즉시 임포트 가능한 `:root` CSS 변수 시트 반환 |
| **패키지 참조** | `GET /templates/api/styles/{style_id}/package` | 메타데이터 + `design-tokens.css` + `CI_AND_STYLE_GUIDE.md` 통합 JSON 반환 |
| **패키지 다운로드** | `GET /templates/api/styles/{style_id}/download` | 선택 스타일 + 커스텀 CI + 샘플 홈페이지 전체 코드가 담긴 `.zip` 아카이브 다운로드 |

## 2. 세부 구현 모듈 구성

1. **백엔드 (`app.py`, `requirements.txt`, `data/twayworks_profile.json`)**:
   - `data/styles_metadata.json`의 10개 스타일 및 `style-00-twayworks-original` 로드.
   - 스타일별 동적 CSS 변수 생성기(`generate_design_tokens_css`) 및 회사 CI & AI 코딩 프롬프트 마크다운 생성기(`generate_ci_and_style_guide_md`) 구현.
   - 인메모리 `zipfile` 모듈을 통해 `README.md`, `CI_AND_STYLE_GUIDE.md`, `style-metadata.json`, `design-tokens.css`, `sample-homepage/`(`index.html`, `css/`, `js/`, `img/` 13종)를 즉시 패키징하여 스트리밍 응답.
2. **프론트엔드 (`static/index.html`, `static/css/`, `static/js/`, `static/img/`)**:
   - `static/css/base-twayworks.css`: 모든 색상, 폰트, 보더, 곡률, 그림자를 `--dh-*` CSS Custom Properties로 추상화하고 10대 스타일별 고유 컴포넌트 특징 반영.
   - `static/css/design-helper-ui.css`: 상단 고정형 Design Helper Studio 바, 10+1 퀵 스타일 스위처 스트립, 정체성 파인더 & CI 커스터마이저 드로어, API & 토큰 인스펙터 모달 스타일링.
   - `static/js/twayworks-app.js`: 12종 프로덕션 스낵 앱 카탈로그 렌더링, 카테고리 필터, 6개 페이지 뷰 라우터, 코어 엔진 탭, 라이트박스 모달 제어.
   - `static/js/design-helper.js`: `/templates/api/styles` 연동, 형용사·동사·업종 매칭 점수 계산, 실시간 CSS 변수 주입, 회사 CI 실시간 편집, API 모달 및 `.zip` 다운로드 트리거.
