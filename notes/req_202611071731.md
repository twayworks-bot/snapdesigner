# 사용자 요구사항 기록 (2026-11-07 17:31)

## 1. 원본 요구사항

> docker container를 생성하기 위한 Dockerfile을 생성하려고 합니다.
> 
> database 파일에 대한 persistent volume을 연동하기 위한 PATH 환경값을 설정합니다.
> 
> 노출 포트는  5000번으로 설정합니다.
> 
> docker 컨테이너의 DEFAULT_PREFIX 환경세팅 값이 있어서 앱의 기본 PREFIX값을 지정합니다.
> 웹앱의  prefix 값는 DEFAULT_PREFIX를 참조 하여  기본 base URL로 작동합니다. 
> 
> 
> 컨테이너 헬스체크 정의 (요청한 사양에 맞춘 Prefix 경로 연동)
> HEALTHCHECK --interval=30s --timeout=10s --retries=3 --start-period=5s \
>     CMD python -c "import os, requests; prefix = os.getenv('DEFAULT_PREFIX', ''); requests.get(f'http://localhost:5000{prefix}/api/status')"
> 
> 
> 시작 CMD 는 다음 2개 중 하나를 참조하여 생성합니다.
> ```
> 1) # Gunicorn 운영서버로 기동 (요청한 사양에 맞춘 최적화 워커 및 디버깅 로그 옵션)
> CMD ["gunicorn", "--bind", "0.0.0.0:5000", "--workers", "2", "--log-level", "debug", "--access-logfile", "-", "--error-logfile", "-", "--capture-output", "main:app"]
> 
> 2) # Run the FastAPI server using Uvicorn on port 5000
> CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "5000"]
> ```
> 
> Dockerfile 조건에 맞게  그리고 URL base경로 값 DEFAULT_PREFIX를 고려하여 코드를 수정해주세요.

## 2. 요구사항 핵심 분석

1. **Docker 컨테이너용 `Dockerfile` 및 `.dockerignore` 생성**:
   - **Database/데이터 영속 볼륨(Persistent Volume) PATH 환경변수 설정**:
     - 컨테이너 내 JSON 데이터베이스 파일(`styles_metadata.json`, `layouts_metadata.json`, `twayworks_profile.json`)을 영구 보존하기 위한 `DATA_DIR` / `DATABASE_PATH` 환경변수 및 `VOLUME ["/app/data"]` 설정.
     - 호스트 빈 디렉토리가 볼륨 마운트되더라도 초기 시드 데이터(`SEED_DATA_DIR`)에서 자동 복원(Seeding)되도록 안전장치 구현.
   - **노출 포트 설정**: `EXPOSE 5000`
   - **기본 Base URL Prefix 환경변수 설정**: `ENV DEFAULT_PREFIX=/templates` (또는 빈 값 `""` 등 유연하게 동작)
   - **컨테이너 헬스체크(`HEALTHCHECK`) 정의**:
     ```dockerfile
     HEALTHCHECK --interval=30s --timeout=10s --retries=3 --start-period=5s \
         CMD python -c "import os, requests; prefix = os.getenv('DEFAULT_PREFIX', ''); requests.get(f'http://localhost:5000{prefix}/api/status')"
     ```
   - **시작 `CMD` 정의 (`main:app` 엔트리포인트 지원)**:
     - Uvicorn 기반 FastAPI 실행 (`CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "5000"]`) 및 Gunicorn 운영 서버 기동 옵션을 모두 지원하도록 엔트리포인트(`main.py`)와 패키지(`requirements.txt`에 `requests`, `gunicorn`, `uvicorn`) 구성.

2. **`DEFAULT_PREFIX` 및 `Dockerfile` 사양에 맞춘 애플리케이션 코드 수정**:
   - **`main.py` 생성**: `CMD ["uvicorn", "main:app", ...]` 및 `CMD ["gunicorn", ..., "main:app"]`이 즉시 동작하도록 `app.py`의 `app` 객체를 export하는 `main.py` 엔트리포인트 모듈 생성.
   - **`DEFAULT_PREFIX` 환경변수 연동 (`app.py`, `static/js/design-helper.js`, `static/index.html`)**:
     - `DEFAULT_PREFIX = os.getenv("DEFAULT_PREFIX", "/templates")`를 읽어 정규화(`""` 또는 `"/..."`)하고, FastAPI 라우터, 정적 파일(`/css`, `/js`, `/img`, `/static`), Swagger 문서(`/docs`, `/redoc`, `/openapi.json`), 루트 리다이렉트, HTML 응답에 동적 반영.
     - 프론트엔드(`static/js/design-helper.js`)가 `window.__DEFAULT_PREFIX__` (서버 주입) 및 현재 URL 경로를 참조하여 어떠한 `DEFAULT_PREFIX` 환경에서도 API 호출과 Swagger 링크가 정상 작동하도록 수정.
   - **`/api/status` 및 `{DEFAULT_PREFIX}/api/status` 헬스체크 엔드포인트 추가**:
     - Docker `HEALTHCHECK`가 호출하는 `http://localhost:5000{prefix}/api/status`가 200 OK 상태와 서비스·데이터베이스·프리픽스 정보를 반환하도록 `@api_router.get("/status")` 엔드포인트 추가.

3. **`README.md` 종합 업데이트**:
   - 프로젝트의 목적, 웹디자인 가이드 기반 v5.0 정보설계(3-Depth 메뉴트리, GNB/LNB/SNB/FNB, 12대 정보 컴포넌트 객체 `IC-01`~`IC-12`, 레이아웃별 계층 재배치 및 특화 뷰 `FV-00`~`FV-10`), 11종 디자인 스타일 & 11종 도메인 레이아웃, Gemini AI 스튜디오 등 전체 기능 설명과 사용법 기록.
   - 로컬 실행 방법(`python main.py`, `uvicorn main:app`, `gunicorn`) 및 **Docker 컨테이너 빌드·실행·영속 볼륨(`DATA_DIR` / `DATABASE_PATH`) 마운트·`DEFAULT_PREFIX` 설정·헬스체크(`/api/status`) 배포 가이드**를 상세히 업데이트.
